# FocusZen – Usability Testing Project

## Overview
FocusZen is an Exam Stress Management UI/UX prototype designed in Figma. This project evaluates usability through real user testing.

## Objective
To analyze how effectively users interact with FocusZen and improve UI/UX design based on feedback.

## Tools Used
- Figma (UI Design)
- Google Forms (Feedback Collection)
- Excel (Data Analysis)

## Testing Method
- 15 users participated
- Tasks:
  - Navigate dashboard
  - Use Pomodoro timer
  - Try mindfulness exercises
  - Check stress tracker

## Key Findings
- High stress among students before exams
- Mindfulness feature is most helpful
- Pomodoro timer improves focus
- Overall usability rating: 4–5 (high)

## Improvements Suggested
- Improve icon clarity
- Add onboarding guide
- Better navigation labels

## Conclusion
FocusZen is a highly usable and effective stress management prototype.
